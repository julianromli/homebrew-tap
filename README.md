# Homebrew tap for Docksly

```bash
brew install --cask julianromli/tap/docksly
```

Docksly saves named Dock layouts and switches them from the menu bar, a keyboard shortcut, the Shortcuts app, or a Focus. See [docksly.faizintifada.com](https://docksly.faizintifada.com/).

The app starts a 7-day trial. After that, it needs a license key.
